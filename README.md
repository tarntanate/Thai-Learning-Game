# ห้องเรียนผจญภัย

เว็บแอปแบบฝึกหัดหลายวิชาระดับประถมศึกษา ผสมผสานกับเกม RPG เก็บเลเวลและสะสมไอเท็ม

## วิชาที่รองรับ

- ภาษาไทย: ป.1–ป.5
- สังคมศึกษา ศาสนา และวัฒนธรรม: ป.1–ป.2 ระดับชั้นละ 100 ข้อ ครอบคลุมศาสนาและพุทธศาสนา คุณธรรม หน้าที่พลเมือง วัฒนธรรม เศรษฐศาสตร์ ประวัติศาสตร์ ภูมิศาสตร์ และสิ่งแวดล้อม
- คณิตศาสตร์: เตรียมโครงสร้างและเมนูไว้แล้ว (เร็ว ๆ นี้)

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิดเซิร์ฟเวอร์สำหรับพัฒนา
npm run build    # ตรวจชนิดข้อมูลและ build สำหรับ production
npm run preview  # ดูผลลัพธ์ที่ build แล้ว
```

## เทคโนโลยีที่ใช้

- Vite + React 19 + TypeScript
- Tailwind CSS 4 (ธีมสว่างแบบ Glassmorphism โทนพาสเทล)
- Motion (Framer Motion) สำหรับอนิเมชัน ตามแนวทางของ [SmoothUI](https://smoothui.dev/docs/guides/vite)
- Web Audio API สำหรับเสียงเอฟเฟกต์ (ไม่ต้องโหลดไฟล์เสียง)
- `localStorage` สำหรับเก็บข้อมูลผู้เล่น (เฟสแรก)

## กติกาเกม

- 1 รอบมี 15 คำถาม สุ่มจากคลังคำถามของแต่ละวิชาและระดับชั้น และเลี่ยงข้อที่เคยเจอแล้ว
- หัวใจ 10 ดวงต่อรอบ ตอบผิดหรือหมดเวลาเสียหัวใจ 1 ดวง หัวใจหมด = จบเกมโดยไม่ได้รางวัล
- เริ่มเล่นแล้วต้องเล่นให้จบ ออกกลางคันไม่ได้
- ยอมแพ้รายข้อได้ไม่เกิน 2 ข้อต่อรอบ (ระบบเฉลยให้)
- โหมดง่าย: 60 วินาที/ข้อ · คำใบ้ฟรี 3 ครั้ง
- โหมดยาก: 30 วินาที/ข้อ · คำใบ้ฟรี 1 ครั้ง · ได้ค่าประสบการณ์ x1.5

### ไอเท็มพิเศษ

| ไอเท็ม             | ความสามารถ                           | ระดับ  |
| ------------------ | ------------------------------------ | ------ |
| ⏰ นาฬิกาเวลา      | เพิ่มเวลาอีก 10 วินาที               | ธรรมดา |
| 🪄 คฑาพ่อมด        | ตัดตัวเลือกผิดออกให้เหลือ 2 ตัวเลือก | หายาก  |
| 🐈 แมวเปลี่ยนคำถาม | เปลี่ยนคำถามข้อนั้นเป็นข้อใหม่       | หายาก  |
| 👩‍🏫 คุณครูช่วยเฉลย  | เฉลยคำตอบที่ถูกต้อง                  | ตำนาน  |

รางวัลเมื่อเล่นจบครบ 15 ข้อ: พลาด 0 ข้อ → ได้คุณครูช่วยเฉลย 1 ชิ้น + สุ่ม 2 ชิ้น, พลาด 1–2 ข้อ → สุ่ม 2 ชิ้น, พลาด 3 ข้อขึ้นไป → นาฬิกา 1 ชิ้น (และหากเลเวลอัป จะได้รับคุณครูช่วยเฉลยเพิ่มพิเศษ 1 ชิ้นต่อเลเวล)

## โครงสร้างโปรเจกต์

```
src/
  components/screens/   หน้าจอหลักของเกม (หน้าแรก, เลือกชั้น, เลือกโหมด, ทำแบบฝึกหัด, สรุปผล)
  components/ui/        คอมโพเนนต์ UI แบบ glassmorphism
  data/                 คลังคำถามแยกตามวิชาและระดับชั้น
  game/                 กติกา ค่าคงที่ ระบบเลเวล และการแจกรางวัล
  hooks/                React hooks (ข้อมูลผู้เล่น, เสียง)
  lib/                  ฟังก์ชันช่วยเหลือทั่วไป
```

## การเพิ่มวิชาหรือระดับชั้นอื่น

1. เพิ่มรหัสวิชาในชนิด `Subject` และข้อมูลเมนู `SUBJECTS`
2. สร้างไฟล์คลังคำถามของวิชาและระดับชั้น โดยใช้รูปแบบ `Question`
3. ลงทะเบียนคลังไว้ใน `BANK` ที่ `src/data/index.ts` เมนูจะเปิดอัตโนมัติเมื่อมีคำถาม
